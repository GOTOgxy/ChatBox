# ChatBox

跨平台 AI 聊天网页聚合器:把 ChatGPT / Gemini / 千问 / DeepSeek 等 AI 网站装进一个桌面应用,侧边栏 + 全局快捷键毫秒级切换,还能从你现有浏览器一键导入登录态——不用重新登录。其他站点(如 Kimi)可通过侧边栏「+」自行添加。

## 功能特性

- **站点聚合**:默认内置 ChatGPT / Gemini / 千问 / DeepSeek,可增删改、自定义图标与颜色、独立快捷键
- **毫秒级切换**:每个站点页面常驻内存,切换不重载;全局快捷键直达站点或唤起窗口
- **登录态导入**:配套 Chrome 扩展,把浏览器里已登录的 Cookie / localStorage 一键搬进应用
- **无边框窗口**:悬浮 / 固定两种标题栏,窗口控制全平台统一右侧;关窗隐藏到托盘
- **云同步**:标准 WebDAV(坚果云 / NAS 等),只同步快捷键与站点名册,**登录态与本机凭据永不上传**
- **自动更新**:应用内检查更新,Windows 静默安装重启,macOS 下载校验后替换重启
- **其他**:深浅主题、网页主题注入、自定义代理、主页设置、下载管理器、开机自启

## 下载安装

到 [GitHub Releases](https://github.com/GOTOgxy/ChatBox/releases/latest) 下载最新版:

| 平台 | 安装包 | 说明 |
|---|---|---|
| Windows | `ChatBox-Setup-x.y.z.exe` | 双击安装,用户级安装,可选安装目录 |
| macOS | `ChatBox-x.y.z-arm64.dmg` | 仅支持 Apple Silicon(M 系列),拖入 Applications |
| Linux | 无(源码运行) | `npm install && npm start`,**未经验证**,暂不提供安装包,见[开发者指南](docs/development.md) |

> ⚠️ **Mac 用户安装后需要多做一步操作**,否则首次打开会提示「已损坏」。详见 [Mac 安装指南](docs/mac-setup.md)。

## 快速上手

- **侧边栏**:左侧图标栏点击切换站点;右键图标 = 在系统浏览器打开;底部「+」添加站点,链条图标 = 导入登录态,齿轮 = 设置。
- **标题栏**:点击侧边栏顶部小 Logo 弹出悬浮标题栏(也可在设置里改为固定模式),含地址栏(Enter 前往)、后退 / 前进 / 刷新 / 回首页,右侧为最小化 / 最大化 / 关闭。空白处可拖动窗口,失焦自动收起。
- **全局快捷键**:设置 → 快捷键页录制,**新安装默认不设置任何快捷键**(不占用系统组合键)。点击输入框后按下组合键即生效,Backspace/Delete 清除,「一键清空全部快捷键」可全部重置。macOS 上 Cmd 与 Ctrl 分别识别。
- **快捷切换面板**:录制「快捷切换面板」快捷键后,随时弹出站点选择器,←→ / 数字选择,Enter 打开,Esc 关闭。
- **托盘**:关闭窗口 = 隐藏到托盘,托盘菜单退出;未读角标依赖页面标题里的 `(n)` 前缀。

## 导入浏览器登录态

1. 应用侧边栏底部点「导入」→「打开扩展管理页」(自动注册本机通信桥)。
2. 在 `chrome://extensions` 开启开发者模式,点「加载已解压的扩展程序」,选择应用提供的 `extension/` 目录(导入面板里有一键复制路径)。
   - 扩展以已解压目录随应用分发,**直接加载即可**。crx 只是可选的打包形式(Chrome 通常拦截商店外 crx),详见 [扩展安装说明](docs/extension.md)。
3. 点浏览器工具栏里的 ChatBox Cookie Bridge 图标 →「发送登录态到 ChatBox」。
4. 回到应用点「导入」,各站点自动注入 Cookie 并刷新。

## 设置与云同步

- **设置页**:主题 / 网页主题、标题栏模式、代理(系统或自定义 HTTP/SOCKS5)、主页、拖动条、GPU 硬件加速、开机自启、数据目录(一键打开)。
- **云同步**(设置 → 同步):基于 WebDAV。填写服务器 / 账号 / 应用密码后点「保存」——保存即存盘,连接测试失败只提示、不会清空已填内容;确认无误后再打开「启用同步」。可手动上传 / 拉取,自动同步有覆盖风险提示。
- 配置存放在系统标准用户目录:Windows `%APPDATA%\ChatBox`、macOS `~/Library/Application Support/ChatBox`、Linux `~/.config/ChatBox`。升级、重装不触碰。

## 自动更新

设置 → 关于 →「检查更新」。Windows 下载 exe 校验后静默安装并重启;macOS 下载 dmg 校验后自动替换应用并重启(应用需位于 /Applications 等可写目录)。macOS 自动更新下载的安装包不带隔离标记,无需额外操作。

## 常见问题

| 问题 | 处理 |
|---|---|
| Mac 提示「已损坏,无法打开」 | 浏览器下载的隔离标记所致,见 [Mac 安装指南](docs/mac-setup.md) |
| 快捷键注册失败 | 组合键被系统或其他软件占用,换一个;输入框会自动还原 |
| Google 登录拦截内嵌浏览器 | 用登录态导入绕过,或改 UA 后重试 |
| 站点无未读角标 | 该站点不往标题写 `(n)` 前缀,属已知边界 |
| Linux(源码运行)Wayland 全局快捷键失效 | 依赖桌面环境支持,X11 正常;Linux 整体未经验证 |
